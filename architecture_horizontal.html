⚡ The 5-Step Execution Pipeline (Real-Time Protocol Sequence)

End-to-End Latency: < 250ms
1
Car ➔ Cloud
Reserve Request
HTTP POST /api/reserve
Driver taps button on car screen. Transmits Station ID, User Token & 30-min duration.
2
Cloud ➔ Kiosk
Remote Lockout
OCPP 1.6 ReserveNow
Cloud dispatches command over WebSocket. Kiosk screen turns BLUE; relay contactor is locked.
3
Car ➔ Kiosk
Driver Arrival & PIN
PIN: [ 4 8 2 9 1 0 ]
Car screen displays one-time PIN. Driver arrives within 30 mins and enters PIN on kiosk keypad.
4
Kiosk ➔ Cloud
OTP Verification
HTTP POST /verify-otp
Kiosk sends entered code to Cloud for authorization. Wrong code triggers RED Access Denied.
5
Cloud ➔ Kiosk
Contactor Closes
RemoteStartTransaction
Cloud approves session. High-voltage relay clicks shut. 60 kW DC charging commences!
